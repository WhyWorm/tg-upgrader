# CS2 Upgrader — Telegram Mini App

Современное Telegram Mini App казино с механикой **CS2 Upgrader** в фирменной стилистике **Telegram Blue (`#229ED9`)**.

## Архитектура и стек

- **Frontend**: React 18, Vite 5, Tailwind CSS
- **Иконки**: Lucide React
- **Звук**: Встроенный синтезатор на базе **Web Audio API** (без внешних аудиофайлов, нулевая задержка)
- **Тактильная отдача**: Интеграция с Telegram WebApp `HapticFeedback` и fallback `navigator.vibrate`
- **Анимации & Конфетти**: `canvas-confetti` + кастомный физический easing для кругового барабана апгрейдера
- **Дизайн**: Тёмная неоновая палитра, CS2-стилистика карточек оружия, радиальный шкальный индикатор апгрейда (Upgrader Wheel Gauge)

---

## Реализованные экраны и компоненты

1. **Главная арена (Upgrader)**:
   - **YOUR ITEM**: Слот выбранного предмета из инвентаря с float-значением, износом (FN/MW/FT) и ценой в TON/USDT.
   - **TARGET ITEM**: Слот целевого скина из каталога с множителем (x1.5 — x50+).
   - **CS2 Upgrader Wheel Gauge**: Круговой радиальный циферблат с сектором победы в градиенте Telegram Blue (`#229ED9` -> `#38b5f2`), индикатором вероятности (0.1% — 95.0%), переключателем стороны вращения (*Roll Under / Roll Over*), кнопками быстрых множителей и плавной физикой замедления стрелки с тиками звука.
   - **Big UPGRADE Button**: Кнопка со свечением Telegram Blue Glow и анимацией вращения.
   - **Переключатель типа ставки**: Выбор скина из инвентаря или прямая ставка с баланса TON.
   - **Live Drops Ticker**: CS2-лента реального времени с последними апгрейдами игроков.

2. **Инвентарь (Inventory)**:
   - Сетка скинов с цветовой кодировкой редкости (★ Special, Covert, Classified, Restricted, Mil-Spec, Industrial).
   - Быстрый поиск и фильтрация по редкости / цене.
   - Быстрые действия: «Апгрейд» и «Быстрая продажа» за TON.
   - Оценка общей стоимости инвентаря.
   - **Бесплатный ежедневный кейс** (Daily Faucet Drop).

3. **История (History)**:
   - Переключение между личными играми и глобальной лентой.
   - Статистика множителя, исходного/целевого скина, результата (WIN/LOSE).
   - Доказательство честности (Provably Fair угол остановки и статус SHA-256).

4. **Профиль (Profile)**:
   - Telegram аватар, username, статус верификации и VIP уровень.
   - Раздельный баланс TON и USDT.
   - Подробная статистика: Общее количество игр, процент побед (Winrate), оборот ставок, рекордный множитель.
   - Система Provably Fair с возможностью генерации клиентского сида.
   - Модальные окна пополнения (TON / Telegram Stars) и вывода средств.

5. **Навигация (Bottom Navigation)**:
   - Мобильный Telegram-стиль с подсветкой активной вкладки цветом `#229ED9` и бейджем количества предметов.
